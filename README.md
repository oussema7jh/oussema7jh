## Selected projects

### [nanorag](https://github.com/oussema7jh/nanorag) · RAG from scratch in pure Python

[![Tests](https://github.com/oussema7jh/nanorag/actions/workflows/tests.yml/badge.svg)](https://github.com/oussema7jh/nanorag/actions/workflows/tests.yml)

A readable, end-to-end RAG pipeline with zero runtime dependencies.

- Covers document ingestion, feature-hashing embeddings, persistent vector storage, and grounded answers with citations.
- Combines BM25 and vector retrieval using Reciprocal Rank Fusion.
- Runs offline with an extractive provider and also supports OpenAI, Anthropic, and Ollama.
- Ships with a bundled evaluation set.

[View the code and quickstart →](https://github.com/oussema7jh/nanorag#quickstart)

### [DiaPredict AI](https://github.com/oussema7jh/diapredict) · Explainable diabetes-risk prediction

An educational full-stack application that makes model predictions interpretable.

- Combines classical ML models and a PyTorch neural network through ensemble inference.
- Explains individual predictions with SHAP.
- Serves results through a FastAPI backend and a React interface.

*Educational and research prototype only; not for medical decisions.*

[Explore the project →](https://github.com/oussema7jh/diapredict)

### [CV Extractor · Pristini JE](https://github.com/oussema7jh/Junior-Entreprise-Cv-Extractor) · AI-assisted CV processing

A job-fair platform that turns uploaded CVs into structured candidate profiles.

- Pairs a Next.js application with a Python worker for document extraction, embeddings, and background processing.
- Lets candidates review their information, while companies search profiles and use QR codes at the fair.
- Shares data across the application and worker through Supabase.

[Explore the project →](https://github.com/oussema7jh/Junior-Entreprise-Cv-Extractor)
